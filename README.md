# Earnzo – Starter Mobile App

This is the first working prototype of Earnzo.

## Included now
- Home feed
- Follow / unfollow
- Like button
- Shorts screen
- Create screen
- Demo publish flow
- Earn tab
- Wallet card
- Brand tasks
- Profile screen
- Bottom navigation

## Run locally
1. Install Node.js.
2. In this folder run:
   npm install
3. Start Expo:
   npx expo start
4. Open with Expo Go on Android, or use Android Studio emulator.
